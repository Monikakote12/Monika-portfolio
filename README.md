Monika Kote – Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my profile, education, technical skills, projects, and career interests as a Computer Science and Engineering student aspiring to become a Java Backend Developer.

🚀 About the Project

This portfolio website is designed to present my academic background, technical knowledge, and development projects in a clean, responsive, and professional format.

It provides visitors with an overview of my journey as a developer and a way to connect with me professionally.

✨ Features

Responsive Design – Works across desktop, tablet, and mobile devices.

About Me – Introduction, education, and career goals.

Skills Section – Highlights my technical skills.

Projects Showcase – Displays my development projects.

Project Filtering – Filter projects by technology.

Dark and Light Mode – Switch between website themes.

Resume Download – Download my resume directly.

Contact Form – Contact me through an email link.

Social Links – Direct links to GitHub and LinkedIn.

Mobile Navigation – Easy navigation on smaller screens.

Scroll Animations – Smooth reveal effects while browsing.

🛠️ Technologies Used
